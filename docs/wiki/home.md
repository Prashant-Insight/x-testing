# Wiki Home

## Purpose

This wiki explains how to use X Testing Dashboard for release readiness, security risk analysis, and end-to-end test planning.

## Pages

- `docs/wiki/end-to-end-testing.md` explains the E2E strategy and recommended coverage.
- `docs/wiki/security-risk-analysis.md` documents the risk model and mitigations.
- `docs/wiki/feature-roadmap.md` lists practical next features for future iterations.

## Recommended Workflow

1. Run the app locally.
2. Complete the checklist while testing user journeys.
3. Review the security risk register.
4. Add analyst notes for release concerns.
5. Generate and download the readiness report.
6. Run validation scripts before submitting changes.
