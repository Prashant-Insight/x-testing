# Feature Roadmap Wiki

## Implemented

- Interactive checklist.
- Readiness score.
- Security risk register.
- Persistent notes.
- Report generation and download.
- Light and dark themes.
- Unit and E2E validation.

## Suggested Next Features

- Import and export checklist templates as JSON.
- Add role-based checklists for QA, security, and product review.
- Add accessibility scan automation.
- Add visual regression tests for dashboard layout.
- Add optional backend storage for team collaboration.

## Prioritization

Prioritize features that improve release confidence without increasing the risk of storing sensitive data in the browser.
